Layout: workspace switcher at the far left, sidebar (Home, DMs, Activity, channels list), conversation in the center, threads/details open on the right, search bar on top.
Shortcuts: jump to conversation ⌘K, search ⌘G (or click the search bar), new message ⌘N, all unreads ⇧⌘A, mark read Esc, edit last message ↑, reply in thread (hover > speech bubble), react (hover > emoji), mention @name, format bold ⌘B / code ⇧⌘C, set status via your avatar.
Channel settings: click the channel name at the top. Notifications: avatar > Preferences.
