Layout: navigator on the left (project files, search, issues, tests, breakpoints), editor in the center, inspectors on the right (file, quick help, attributes), debug area at the bottom, toolbar on top with Run/Stop, scheme and destination pickers.
Shortcuts: build ⌘B, run ⌘R, stop ⌘., test ⌘U, clean build folder ⇧⌘K, open quickly ⇧⌘O, toggle navigator ⌘0, toggle inspectors ⌥⌘0, toggle debug area ⇧⌘Y, find in project ⇧⌘F, jump to definition ⌃⌘J, canvas/preview ⌥⌘Return.
Add a package: File > Add Package Dependencies. Signing: target > Signing & Capabilities.
