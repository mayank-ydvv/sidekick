Layout: sidebar on the left (Favorites, iCloud, Locations, Tags), toolbar on top (back/forward, view switcher, group, share, tags, action "…", search), file area in the middle, path bar/status bar at the bottom (View menu to show them).
Views: icon ⌘1, list ⌘2, columns ⌘3, gallery ⌘4.
Common tasks:
- New folder: File > New Folder or ⇧⌘N (in the current window). Rename: select + Return.
- New Finder window ⌘N, new tab ⌘T. Go to folder: ⇧⌘G.
- Copy ⌘C, paste ⌘V, move instead of copy: ⌥⌘V. Duplicate ⌘D. Move to Bin ⌘⌫.
- Get Info ⌘I. Quick Look: Space. Show hidden files ⇧⌘.
- Compress: right-click > Compress. Sort/group via the toolbar group button or View > Show View Options (⌘J).
- AirDrop/Share: select file > toolbar share button.
