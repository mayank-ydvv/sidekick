Layout: activity bar on the far left (Explorer, Search, Source Control, Run & Debug, Extensions), side bar next to it, editor tabs in the center, panel at the bottom (Terminal, Problems, Output, Debug Console), status bar at the very bottom (branch, errors, language mode).
Shortcuts: command palette ⇧⌘P, quick open file ⌘P, toggle sidebar ⌘B, terminal ⌃`, find ⌘F, find in files ⇧⌘F, go to symbol ⇧⌘O, go to definition F12, rename symbol F2, multi-cursor ⌥click, format ⇧⌥F, settings ⌘,.
Git: Source Control view (⌃⇧G), stage with "+", commit message box on top, ✓ to commit.
Extensions: ⇧⌘X, search and click Install.
