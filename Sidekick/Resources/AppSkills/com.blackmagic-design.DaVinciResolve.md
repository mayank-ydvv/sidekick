Layout: page tabs along the very bottom — Media, Cut, Edit, Fusion, Color, Fairlight, Deliver. Each page has its own panels: Media Pool (top left on Edit), Viewer(s) top center/right, Inspector top right (toggle at top right), Timeline at the bottom.
Edit page: blade tool B, selection A, trim T, split at playhead ⌘B, ripple delete ⇧⌫, play/stop Space, J/K/L shuttle, mark in I / out O, zoom timeline ⌘+/⌘−, snapping N, linked selection ⇧⌘L.
Import: Media page or drag files into the Media Pool. Color page: nodes graph top right, color wheels bottom left, add serial node ⌥S.
Export: Deliver page → choose preset (e.g. YouTube/H.264), set location, "Add to Render Queue", then "Render All" on the right.
