Layout: left sidebar with Design (templates), Elements, Text, Brand, Uploads, Draw, Projects, Apps; canvas in the middle with pages stacked vertically; top bar with File, Resize, undo/redo, title, Share; contextual toolbar above the canvas changes with the selected item.
Tasks: add text via Text tab or T, add images via Uploads or Elements, change colors via the color square in the contextual toolbar, position/align via "Position", animate via "Animate", remove background via Edit image > BG Remover (Pro), add a page with "+ Add page".
Download: Share > Download, pick file type (PNG/JPG/PDF/MP4) and click Download.
