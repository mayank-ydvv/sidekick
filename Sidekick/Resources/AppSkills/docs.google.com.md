Shared layout: menu bar (File, Edit, View, Insert, Format, Tools, Extensions, Help) under the title, toolbar below it, Share button at top right, comments icon next to it. Search the menus: ⌥/.
Docs: headings via the "Normal text" dropdown, insert link ⌘K, comment ⌥⌘M, word count ⇧⌘C, suggesting mode via the pencil dropdown at top right, version history File > Version history.
Sheets: formulas start with =; fill down ⌘D; freeze rows View > Freeze; filter via the funnel icon; conditional formatting Format > Conditional formatting; charts Insert > Chart; insert rows by right-clicking a row number.
Slides: new slide ⌃M, present ⌘Return, themes via the "Theme" button, speaker notes below the slide.
