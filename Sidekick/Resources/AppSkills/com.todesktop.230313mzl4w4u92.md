Cursor is a VS Code–based editor with AI built in. Layout matches VS Code (activity bar left, editor center, panel bottom) plus an AI chat/agent pane on the right.
AI: open chat/agent pane ⌘L (or ⌘I depending on version), inline edit in the editor ⌘K, accept suggestion Tab, reject Esc. Add files to context with @ in the chat box.
Same core shortcuts as VS Code: ⇧⌘P palette, ⌘P quick open, ⌃` terminal, ⌘B sidebar, ⇧⌘F search.
Settings: Cursor > Settings (gear in top right) for models, rules and features; VS Code settings via ⌘,.
