Window with a shell prompt; new window ⌘N, new tab ⌘T, close ⌘W, clear screen ⌘K, find ⌘F, interrupt a running command ⌃C, previous commands ↑, search history ⌃R, autocomplete Tab.
Common commands: ls (list), cd folder (go into), cd .. (up), pwd (where am I), mkdir name, open . (open folder in Finder), cat file, cp/mv/rm (rm is permanent — careful).
Profiles/appearance: Terminal > Settings > Profiles. Never paste commands you don't understand that use sudo or rm -rf.
