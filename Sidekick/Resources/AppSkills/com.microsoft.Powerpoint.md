Layout: ribbon on top (Home, Insert, Draw, Design, Transitions, Animations, Slide Show, Review, View), slide thumbnails on the left, slide canvas in the middle, notes pane below (View > Notes).
Tasks: new slide ⇧⌘N (or Home > New Slide), layouts Home > Layout, themes Design tab, Designer ideas Design > Designer, transitions tab for slide transitions, Animations tab for object animations + Animation Pane, present from start ⇧⌘Return, from current slide ⌘Return.
Insert images/shapes/charts via the Insert tab. Align objects: Arrange > Align (Shape Format tab).
