name: Google Chrome
match: com.google.chrome, com.google.chrome.canary
---
Layout: tabs on top, address bar (omnibox) below, extensions puzzle icon and profile avatar to the right, three-dot menu at far right (settings, history, downloads, bookmarks, more tools).
Shortcuts: new tab ⌘T, reopen closed tab ⇧⌘T, address bar ⌘L, find ⌘F, history ⌘Y, downloads ⇧⌘J, bookmarks manager ⌥⌘B, incognito ⇧⌘N, dev tools ⌥⌘I, switch tab ⌘1–⌘9.
Settings: three-dot menu > Settings (chrome://settings). Clear data: ⇧⌘⌫. Extensions: chrome://extensions. Tab groups: right-click a tab > Add tab to group.
