Layout: ribbon on top (Home, Insert, Draw, Page Layout, Formulas, Data, Review, View), formula bar under it with the Name Box on the left, grid in the middle, sheet tabs at the bottom left.
Basics: formulas start with =, AutoSum ⇧⌘T, fill down ⌘D, edit cell F2 (or ⌃U), insert row/column via right-click on the header, freeze panes View > Freeze Panes, filter Data > Filter (⇧⌘F), sort Data > Sort, PivotTable Insert > PivotTable, chart Insert > (pick chart), conditional formatting Home > Conditional Formatting.
Lookups: XLOOKUP(lookup, lookup_range, return_range). Absolute refs with $ (⌘T toggles while editing).
