Layout: sidebar on the left (search, home, inbox, teamspaces, private pages, "+" new page), page in the center, Share/comments/updates/"•••" at top right.
Editing: type "/" for the block menu (heading, to-do, table, database, toggle, callout, code). Drag the ⋮⋮ handle to move blocks. Markdown shortcuts work (# heading, - bullet, [] to-do, > toggle, ``` code).
Shortcuts: search ⌘P (or ⌘K), new page ⌘N, link ⌘K on selected text, turn into another block ⌘/ , duplicate ⌘D, dark mode ⇧⌘L.
Databases: "/database" or "/table"; views (table/board/calendar/gallery) via "+ Add a view" above the database.
